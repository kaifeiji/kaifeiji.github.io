般若波罗蜜多

发表于 2026-11-11 分类于 随笔

Gate gate pāragate pārasaṃgate bodhi svāhā.

如是我闻

年轻时对于佛教的理解，要么是和尚敲木鱼打坐、吃斋念佛，要么就是少林武僧、十八铜人，还有一些民间传颂的敲头、烫手、打机锋。

早几年困顿的时候，买了一本《金刚经》，半懂不懂的，也读，也抄，企图从中获取些许慰藉或解脱。然而并没有什么卵用，悟性太差，还是从现实中辗转腾挪，跳出了困境。

闲来无事，从收藏夹里翻出来一个佛经网站：如是我闻。这个网站的作者也是一个程序员，做的 UI 古色古香，颇具佛学韵味。

项目缘起中，作者提出了美好的愿望：

愿我们在代码与经卷之间，共修、共见本心。

心经

《心经》比《金刚经》要短得多，只有 260 个字。一眼望过去，仍然是熟悉的“空”、“无我”、“非法非非法”、“不可说”。粗鄙理解如下：

舍利子啊，没有什么空，也没有什么色。生死是虚妄，思想、行为、认识也都是想象的共同体。外在的器官、内在的感受，甚至意识本身也是假的。没有苦难、缘起、灭失和开解之道。没有智慧，也没有证得。

舍利子啊，就是因为心无牵挂，才没有恐惧，远离幻觉，终证涅槃。

这时世尊宣说咒语道：

Gate gate pāragate pārasaṃgate bodhi svāhā.

俗人

法非法，我非我，彼岸非彼岸。对我这个俗人来说，读经似乎是徒劳无功的修心。

如果佛的理念是不可说的，那读经有用吗？禅宗里有一个经典的隐喻：经书就像是用来指向月亮的那根手指，而“不可说”的真理是月亮本身。一旦你找到了月亮，你会欣喜若狂，然后把手剁掉（法尚应舍）。

但是对俗人来说，别说剁手了，就是不小心丢了一百块钱也要心疼一会儿的。更别说把“我”舍弃掉了，这简直是不可想象的。

就像我没法想象我死后的世界，我也没法想象“我”把“我”抛弃的境界。

舍弃

初高中，喜欢看周国平的《安静的角落》，觉得自己可孤独了，经常独自享受文艺优越小伤感。

那时候我还写日记，后来全烧了。因为后来的“我”觉得初高中的“我”太 der 了！

年少时构建的诗意、宁静、爱与孤独，随着一把火，被彻底舍弃。

我现在忙着在世俗里上班挣钱，带孩子写作业，吃饭、刷碗、打魔兽。

抛弃自恋！拥抱金钱！

我突然觉得，我悟了：

走，一起去彼岸，大彻大悟，功德圆满。哈哈！
